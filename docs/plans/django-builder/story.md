# Story
A clan leader signs in with Discord, creates a home for the community, edits real formatted text, adds images, previews and publishes. A teammate can edit only sites they belong to. A bot can draft only for the exact tenant and Discord context it was bound to. No code editor, infrastructure dashboard or arbitrary application generation.

Acceptance: smooth desktop/mobile flows, separated draft/live content, recoverable history, tenant-scoped media and API, real MySQL, Discord OAuth and signed interaction validation, quota enforcement, migration import without remote execution, documented hosted setup. No live-site cutover or credential migration in this PR.
